# Full clean packaging architecture

Product ownership/timing/storage remain as in the full functional source: Main/Home own routes and profile lifetime; Scheduler owns musical time; activities retain original Session/source bindings; ProfileStore serializes durable facts and recovery. New Guided activity remains disabled.

The new CleanRuntimeEnvelope capability is minted only after the compiled transport pin and physical closure validate. Its physical transport hash is distinct from the original logical bundle manifest identity used in Admission/cache/recovery. Existing package/profile/registry/decision bytes remain unchanged.

Archived-evidence verification is explicit and digest/role/path/size-bound. It verifies minimal pinned historical identity metadata without claiming the old prose was read. Raw assets still need real bytes. Only predecessor validation has a typed semantic projection API; each preserved record's canonical digest is verified. No generic readBounded fallback or omitted-file wildcard is permitted.

The loader validates retained payloads/projections and rechecks current metadata/payload state for cache reuse. Unknown omissions, changed files, extra files and symlinks refuse. This is a packaging/data-loading boundary, not a new admission policy or product redesign.

Source/curriculum IDs and stored schema meaning stay stable. Software source hashes can change with the loader implementation; they are not substituted for logical content identity. Rights-sensitive genuine curriculum is retained privately, while known QA/planning prose is archived separately.
