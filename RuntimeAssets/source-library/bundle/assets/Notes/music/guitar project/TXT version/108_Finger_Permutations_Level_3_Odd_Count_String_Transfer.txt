108 FINGER PERMUTATIONS - LEVEL 3: ODD-COUNT STRING TRANSFER
3+1 / 1+3 split-point control in standard tuning.
Fifth position: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.

MOVEMENT RULE
Mode A - 3+1 late transfer: play digits 1-3 on the first string and digit 4 on the adjacent string.
Mode B - 1+3 early transfer: play digit 1 on the first string and digits 2-4 on the adjacent string.
Ascend through E/A, A/D, D/G, G/B, B/e. Descend through e/B, B/G, G/D, D/A, A/E.
The four-digit code order never changes.

WHY THIS IS LEVEL 3
Level 2 crossed after note 2. These modes cross after note 3 or note 1, so strict alternate picking produces different
inside- and outside-string transitions depending on whether the exercise begins with a downstroke or an upstroke.

PRACTICE RULE
Begin 8-12 BPM below your clean Level 2 tempo. Use one 12-code set and one mode per session.
Play each exercise ascending and descending, once beginning with a downstroke and once beginning with an upstroke.
First pass: lightly accent the first note after the crossing. Second pass: make all four notes equal in volume.
Rotate the existing straight-16th, triplet, and quintuplet groupings across sessions.
After three clean loops, add 2 BPM next time. After two errors or rising tension, reduce 4-6 BPM.
Advance when both modes for the set are clean on two separate days.
