108 FINGER PERMUTATIONS - LEVEL 6: ODD-COUNT STRING-SKIP TRANSFER
3+1 / 1+3 gap control in standard tuning.
Fifth position: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.

MOVEMENT RULE
Mode A - 3+1 late skip: play digits 1-3 on the source string, clear one silent string, and land digit 4 on the target.
Mode B - 1+3 early skip: play digit 1 on the source string, clear one silent string, and continue digits 2-4 on the target.
Ascend through E-D, A-G, D-B, G-e. Descend through e-G, B-D, G-A, D-E.
The four-digit code order never changes. The physical string between source and target must remain silent.

WHY THIS IS LEVEL 6
Level 5 crossed the gap after note 2. Level 6 keeps the same one-string-skip distance but moves the crossing after note 3
or note 1. This combines the asymmetrical alternate-picking timing from Level 3 with the muting and landing demands of Level 5.

PRACTICE RULE
Begin 8-12 BPM below your clean Level 5 tempo. Use one 12-code set and one mode per session.
Play each exercise ascending and descending, once beginning with a downstroke and once beginning with an upstroke.
First pass: lightly accent the first note after the skip and verify that the middle string remains silent.
Second pass: remove the accent, equalize all four notes, and keep the pick path shallow and compact.
Start with separated four-note cells. Connect the complete route only after every landing is clean.
Rotate the existing straight-16th, triplet, and quintuplet groupings across sessions.
After three clean loops, add 2 BPM next time. After two noisy skips, errors, or rising tension, reduce 4-6 BPM.
Advance when both modes for the set are clean on two separate days. Then alternate 3+1 and 1+3 between successive skip pairs.
