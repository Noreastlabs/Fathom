A HARMONIC MINOR INTERVAL SEQUENCES, ARPEGGIO OVERLAYS, MODE FUNCTIONS, AND PROGRESSION-SPECIFIC MELODIC APPLICATIONS

PURPOSE

ERROR DIAGNOSIS
MODE NAME WITHOUT FUNCTION: hold the chord or drone and stop on its root.
INTERVAL RUN BECOMES SCALE: remove the connecting notes; play only the pair.
AUG2 RUSH: isolate F-G# and keep equal subdivisions.
V7 SOUNDS MINOR: accent G# before adding F or C color.
DIMINISHED CELL SOUNDS RANDOM: state G#dim7, then resolve every voice.
III+ SOUNDS UNSTABLE: land C-E-G# first; add B only after the triad is clear.
FORM LOSS: return to quarter-note chord tones and name each bar.
