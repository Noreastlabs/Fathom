108 FINGER PERMUTATIONS - LEVEL 7: THREE-STRING SKIP RELAY
1+2+1 double-gap crossing and muting control in standard tuning.
Fifth position: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.

MOVEMENT RULE
Play code note 1 on the first played string, code notes 2-3 on the middle played string, and code note 4 on the third.
Leave one physical string silent between the first and middle played strings and another silent string between the middle
and third played strings. Ascend through E-D-B and A-G-e. Descend through e-G-A and B-D-E.
The 1+2+1 description refers to note counts, not finger numbers. The four-digit code order never changes.

WHY THIS IS LEVEL 7
Level 4 introduced the 1+2+1 relay across adjacent strings. Levels 5 and 6 trained one skipped-string crossing at
different rhythmic points. Level 7 combines those skills: both crossings in the relay now clear a silent string.
This doubles the number of skipped-string landings per code without adding a position shift or a wider individual leap.

PRACTICE RULE
Use one 12-exercise set per session. Begin 10-15 BPM below the slower of your two clean Level 6 modes.
Play ASCEND directly into DESCEND, then repeat the entire exercise with the opposite starting pick stroke.
First pass: separate the four-note cells, use short notes, and lightly accent landing notes 2 and 4.
Verify that both intervening strings remain silent and that neither crossing becomes an exaggerated vertical jump.
Second pass: connect the route, remove the accents, and equalize all four notes in volume, timing, and duration.
Use straight 16ths first. Reintroduce triplet and quintuplet groupings only after both gap landings are stable.
After three clean loops, add 2 BPM next session. After two noisy gaps, errors, or rising tension, reduce 4-6 BPM.
Advance after the full set is clean with both pick starts on two separate days.
