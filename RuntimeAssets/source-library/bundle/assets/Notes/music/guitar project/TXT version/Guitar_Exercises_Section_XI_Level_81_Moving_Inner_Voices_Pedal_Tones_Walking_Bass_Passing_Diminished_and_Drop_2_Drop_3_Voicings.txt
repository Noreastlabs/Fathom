Guitar Exercises - Section XI, Level 81
MOVING INNER VOICES, PEDAL TONES, WALKING BASS, PASSING DIMINISHED CHORDS, DROP-2 / DROP-3 VOICINGS

PURPOSE
Extend chord melody from static outer-voice control into moving internal architecture while preserving melody, bass, pulse, and harmonic function.

MODULE A - MOVING INNER VOICES
Cmaj7: line B-C-B-A; degrees 7-R-7-6; C bass; hold E or G as lower inner voice.
Am7: line G-G#-A-G; degrees b7-7-R-b7; A bass; G# is a chromatic passing voice; do not rename Am.
Dm7: line C-C#-D-C; degrees b7-7-R-b7; D bass; chromatic upper neighbor resolves into D.
G7: line F-F#-G-F; degrees b7-7-R-b7; G bass; F# is a passing tone, not a new chord quality.
Cmaj7 -> A7: line B-Bb-A-G#; degrees 7-b7-6-#5; C -> A bass; hear the inner descent while melody E stays fixed.
Dm7 -> G7: line C-B-Bb-B; degrees b7-3-b3-3; D -> G bass; target B as the G7 third.

MODULE B - PEDAL TONES
High E pedal: harmony Cmaj7 | Am7 | Fmaj7 | E7; pedal E-E-E-E; functions E = 3,5,7,root.
High G pedal: harmony Cmaj7 | Em7 | Am7 | G7; pedal G-G-G-G; functions G = 5,b3,b7,root.
High C pedal: harmony Am7 | Fmaj7 | Dm7 | G7; pedal C-C-C-C; functions C = b3,5,b7,11.
Bass C pedal: harmony Cmaj7 | Dm7/C | G7/C | Cmaj7; pedal C-C-C-C; functions upper harmony changes above fixed tonic.
Bass A pedal: harmony Am7 | D/A | F/A | E7/A; pedal A-A-A-A; functions hear 1,5,3,11 over changing upper structure.
Inner E pedal: harmony Cmaj7 | Am7 | Fmaj7 | E7; pedal E-E-E-E; functions retain one middle voice while outer voices move.

MODULE C - WALKING BASS
C major descending: bass C-B-A-G; harmony Cmaj7 -> Cmaj7/B -> Am7 -> G7.
A minor descending: bass A-G-F-E; harmony Am7 -> G7 -> Fmaj7 -> E7.
C major ascending: bass C-D-E-F; harmony Cmaj7 -> Dm7 -> Em7 -> Fmaj7.
A minor ascending: bass A-B-C-D; harmony Am7 -> Bm7b5 -> Cmaj7 -> Dm7.
Approach G7: bass D-E-F-F# -> G; harmony Dm7 over D-E-F-F#, then G7.
Approach Cmaj7: bass G-F-E-D-Db -> C; harmony G7 descent with chromatic Db approach.
Approach Am7: bass E-F-F#-G-G# -> A; harmony E7 / passing diminished color into Am.
Turnaround walk: bass C-B-Bb-A-Ab-G; harmony Cmaj7 -> C7/Bb -> A7 -> Ab7 -> G7 color route.

MODULE G - INDEPENDENT-VOICE INTEGRATION
Pedal melody + walking bass: Melody G held; bass C-B-A-G; Cmaj7 -> Cmaj7/B -> Am7 -> G7.
Pedal bass + moving top: C bass; melody E-F-G-E; Cmaj7 -> Dm7/C -> G7/C -> Cmaj7.
Walking bass + guide dyad: Bass D-E-F-F# -> G; guide voices C->B and F->F over Dm7->G7.
Passing diminished + melody: Cmaj7 -> C#dim7 -> Dm7; hold G on top, then resolve to F or A.
Drop-2 comp + melody answer: Cmaj7 / Am7 / Dm7 / G7; one blocked voicing, then two-note top-line answer.
Spread voicing + bass fill: Cmaj7 -> Am7; hold upper three notes; bass walks C-B-A.
Contrary outer voices: Bass C-D-E-F; melody G-F-E-D; inner thirds/sevenths only on beats 1 and 3.
Reduction ladder: full voicing -> drop inner -> bass+melody -> melody; restore voices in reverse order.

MODULE J - RECOVERY
Melody disappears: remove one inner voice; restore bass + melody first.
Pedal tone breaks: freeze upper/lower voices; rebuild harmony around the pedal.
Walking bass arrives late: reduce chord to shell; make bass land on beat 1.
Passing diminished sounds random: play source and destination only; reinsert diminished as one-beat connector.
Drop-2 grip is noisy: arpeggiate four voices; restore blocked attack after clean scan.
Spread voicing causes stretch: omit fifth or extension; preserve melody, bass, and guide tone.
Voice crossing confuses melody: move inner voice down an octave; keep top line highest.
Form lost: roots + melody targets only; re-enter full texture at cadence.

MASTERY
