GUITAR EXERCISES - SECTION VI, LEVEL 57
SEVENTH CHORDS, SHELL VOICINGS, MAJOR AND MINOR ii-V-I, AND FUNCTIONAL VOICE LEADING

PURPOSE
Add the seventh to major, dominant, minor, and half-diminished chords; learn practical E-root and A-root voicings; reduce those voicings to shells; move thirds and sevenths through major ii-V-I and minor iiø-V-i cadences; apply shells to A blues; and arpeggiate the full chord spellings.

FORMULAS
maj7 = 1-3-5-7
7 = 1-3-5-b7
m7 = 1-b3-5-b7
m7b5 = 1-b3-b5-b7

SHELL LIMITATION
m7 and m7b5 have the same root-b3-b7 shell. The b5 must be added or heard elsewhere to identify half-diminished quality.

WORKLOAD
Module A: 56 silent formations.
Module B: 112 E-root attacks.
Module C: 112 A-root attacks.
Module D: 56 quality-ladder attacks.
Module E: 108 major ii-V-I attacks.
Module F: 108 minor iiø-V-i attacks.
Module G: 108 A-blues shell-comping attacks.
Module H: 64 arpeggio attacks.
Module I: 128 capstone attacks.
COMPLETE SOUNDED WORKOUT: 796 attacks.

========================================================================================================================
MODULE D - SHELL VOICINGS AND QUALITY LADDERS
========================================================================================================================
E-root shells on E-D-G:
maj7 r-x-r+1-r+1 = R-7-3
7 r-x-r-r+1 = R-b7-3
m7 r-x-r-r = R-b7-b3
m7b5 uses the same shell; add B-string r-1 for b5.

A-root shells on A-G-B:
maj7 x-r-x-r+1-r+2 = R-7-3
7 x-r-x-r-r+2 = R-b7-3
m7 x-r-x-r-r+1 = R-b7-b3
m7b5 uses the same shell; add D-string r+1 for b5.

A E-root ladder: Amaj7 -> A7 -> Am7 -> Am7b5 -> Am7 -> A7 -> Amaj7. Repeat four times.
D A-root ladder: Dmaj7 -> D7 -> Dm7 -> Dm7b5 -> Dm7 -> D7 -> Dmaj7. Repeat four times.
