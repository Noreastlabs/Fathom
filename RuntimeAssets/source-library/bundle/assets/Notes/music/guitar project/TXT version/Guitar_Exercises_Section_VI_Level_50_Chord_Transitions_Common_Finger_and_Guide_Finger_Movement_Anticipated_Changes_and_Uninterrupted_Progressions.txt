GUITAR EXERCISES - SECTION VI, LEVEL 50
CHORD TRANSITIONS, COMMON-FINGER AND GUIDE-FINGER MOVEMENT, ANTICIPATED CHANGES, AND UNINTERRUPTED PROGRESSIONS

PURPOSE
Keep the eight open-chord shapes from Level 49 while reducing excess movement, preserving planted fingers, using guide fingers, controlling pressure release, anticipating changes on the and of 4, and maintaining longer progressions without a reset.

COMPLETE NOTATED WORKLOAD: 768 strum or pick attacks plus 80 silent chord landings before optional repeats.


========================================================================================================================
CHORD REFERENCE
========================================================================================================================
Em: frets 0 2 2 0 0 0 | fingers O 2 3 O O O | spelling E G B | attack all 6 strings
E: frets 0 2 2 1 0 0 | fingers O 2 3 1 O O | spelling E G# B | attack all 6 strings
Am: frets x 0 2 2 1 0 | fingers x O 2 3 1 O | spelling A C E | attack A string through high e
A: frets x 0 2 2 2 0 | fingers x O 2 1 3 O | spelling A C# E | attack A string through high e
Dm: frets x x 0 2 3 1 | fingers x x O 2 3 1 | spelling D F A | attack D string through high e
D: frets x x 0 2 3 2 | fingers x x O 1 3 2 | spelling D F# A | attack D string through high e
C: frets x 3 2 0 1 0 | fingers x 3 2 O 1 O | spelling C E G | attack A string through high e
G: frets 3 2 0 0 0 3 | fingers 2 1 O O O 3 | spelling G B D | attack all 6 strings

ALTERNATE TRANSITION FINGERINGS
Em-alt: frets 0 2 2 0 0 0 | fingers O 1 2 O O O | Use for G-Em and Em-C so A2 or D2 can stay planted.
E-alt: frets 0 2 2 1 0 0 | fingers O 3 2 1 O O | Use for E-C so finger 2 stays on D2.

========================================================================================================================
MODULE A - SILENT TRANSITION MECHANICS
========================================================================================================================
Count 1: hold current chord. Count 2: release pressure while preserving anchors. Count 3: move guide and remaining fingers. Count 4: land and inspect. Reverse the transition on the next four counts.
E-Em: two planted fingers; 8 silent landings.
D-Dm: one planted finger; 8 silent landings.
C-Am: two planted fingers; 8 silent landings.
A-Am: one planted finger; 8 silent landings.
G-Em-alt: one planted finger; 8 silent landings.
Em-alt-C: one planted finger; 8 silent landings.
A-D: one planted finger; 8 silent landings.
E-A: same-string guide slide; 8 silent landings.
D-G: same-fret guide transfer; 8 silent landings.
G-C: same-fret long transfer; 8 silent landings.
Audit: low hover distance, no string drag, correct bass-side landing, relaxed thumb, no strum.

========================================================================================================================
PRACTICE PROGRESSION AND ERROR REPAIR
========================================================================================================================
1. Transition taxonomy
2. Silent mechanics
3. Common fingers
4. Guide transfers
5. Release timing
6. Anticipated changes
7. Half-beat bursts
8. One-beat progressions
9. Eight-bar routes
10. Sixteen-bar capstones
ANCHOR SQUEEZES: keep contact but reduce pressure.
GUIDE SQUEAKS: release before sliding or transferring.
LATE BASS: land from the bass side and narrow the strum.
EARLY RELEASE: hold through the printed count.
PUSH IS EARLY: count 4 and before the upstroke.
PUSH IS LATE: prepare during beat 4, not after it.
BURST COLLAPSES: shorten to one bar and reduce tempo.
FORM RESET: say the next chord one beat early.
PAIN OR TENSION: stop, reduce duration, and return to silent mechanics.
