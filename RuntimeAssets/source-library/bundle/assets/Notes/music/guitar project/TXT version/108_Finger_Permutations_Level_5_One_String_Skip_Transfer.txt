108 FINGER PERMUTATIONS - LEVEL 5: ONE-STRING-SKIP TRANSFER
2+2 gap crossing and muting control in standard tuning.
Fifth position: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.

MOVEMENT RULE
Return to the even 2+2 split so that string skipping is the only new variable.
Play digits 1-2 on the source string and digits 3-4 on the target string, leaving exactly one physical string between them.
Ascend through E-D, A-G, D-B, G-e. Descend through e-G, B-D, G-A, D-E.
The four-digit code order never changes. The skipped middle string must remain silent.

WHY THIS IS LEVEL 5
Level 4 trained two crossings across three adjacent strings. Level 5 reduces the code to one crossing but increases the
distance of that crossing. This isolates string-skipping, pick-path, and muting control without adding a position shift.

PRACTICE RULE
Begin 10-15 BPM below your clean Level 4 tempo. Use one 12-code set per session.
Play each exercise ascending and descending, once beginning with a downstroke and once beginning with an upstroke.
First pass: lightly accent note 3, the first note after the skip, and listen for accidental skipped-string contact.
Second pass: make all four notes equal in volume, keep the middle string silent, and minimize unnecessary pick travel.
Rotate the existing straight-16th, triplet, and quintuplet groupings across sessions.
After three clean loops, add 2 BPM next time. After two noisy skips, errors, or rising tension, reduce 4-6 BPM.
Advance when the complete set is clean with both pick-start directions on two separate days.
