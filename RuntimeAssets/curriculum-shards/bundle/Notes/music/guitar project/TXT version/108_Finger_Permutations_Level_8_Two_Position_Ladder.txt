108 FINGER PERMUTATIONS - LEVEL 8: TWO-POSITION LADDER
4+4 whole-pattern position-shift control in standard tuning.
P5 mapping: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.
P7 mapping: 1=index/fret 7, 2=middle/fret 8, 3=ring/fret 9, 4=pinky/fret 10.

MOVEMENT RULE
Play the complete four-digit code in fifth position, release pressure, shift the entire hand frame two frets,
and repeat the same code in seventh position. For the return route, play the code in seventh position first,
then shift down and repeat it in fifth position. The shift occurs only between complete four-note cells.
Play SHIFT UP on E-A-D-G-B-e and SHIFT DOWN on e-B-G-D-A-E, one string at a time.
The repeated aligned tab lines are a compact map; they are not simultaneous chord tones.

WHY THIS IS LEVEL 8
Levels 1-7 developed vertical movement while the fretting hand remained in fifth position. Level 8 starts the
horizontal-mobility branch. It deliberately removes in-cell string crossing so release pressure, target-fret
accuracy, thumb movement, and hand-frame reconstruction can be learned as separate skills.

PRACTICE RULE
Use one 12-exercise set per session. Begin 10-15 BPM below your clean Level 1 same-string tempo.
First pass: play even eighth notes, pause one subdivision at the center barline, and lightly accent the first
note after the shift. Second pass: remove the pause and accent, then convert the 4+4 phrase to straight 16ths.
Play both routes with a downstroke start, then repeat with an upstroke start. Because each cell contains four
notes, the second cell begins with the same pick direction; this keeps the new difficulty in the fretting hand.
After three clean loops, add 2 BPM next session. After two late landings, fret squeaks, errors, or rising tension,
reduce 4-6 BPM. Advance after the full set is clean in both directions on two separate days.
