108 FINGER PERMUTATIONS - LEVEL 4: THREE-STRING RELAY
1+2+1 two-crossing control in standard tuning.
Fifth position: 1=index/fret 5, 2=middle/fret 6, 3=ring/fret 7, 4=pinky/fret 8.

MOVEMENT RULE
For every adjacent three-string group, play code note 1 on the first string, code notes 2-3 on the middle string,
and code note 4 on the third string. The 1+2+1 description refers to note counts, not finger numbers.
Ascend through E/A/D, A/D/G, D/G/B, G/B/e. Descend through e/B/G, B/G/D, G/D/A, D/A/E.
The four-digit code order never changes. There is no string skip or position shift yet.

WHY THIS IS LEVEL 4
Levels 2 and 3 used one adjacent-string crossing per four-note code. Level 4 adds a second crossing.
With a downstroke start, notes 2 and 4 land on upstrokes. With an upstroke start, both land on downstrokes.
Practicing both starts exposes both pick-escape directions while the fretting position remains fixed.

PRACTICE RULE
Use one 12-exercise set per session. Start 10-15 BPM below your clean Level 3 tempo.
Play ASCEND directly into DESCEND, then repeat the entire exercise with the opposite starting pick stroke.
First pass: lightly accent landing notes 2 and 4. Second pass: make all four notes equal in volume and duration.
Use straight 16ths first. Reintroduce triplet and quintuplet groupings only after the crossings are stable.
After three clean loops, add 2 BPM next session. After two errors or rising tension, reduce 4-6 BPM.
Advance after the full set is clean with both pick starts on two separate days.
