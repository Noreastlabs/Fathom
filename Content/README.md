# Curriculum and runtime content

The current application represents the approved 105 source workbooks. All 7,271 definite implementation children have version-bound accepted engineering evidence; the 7,321 indexed source units also include 33 legacy/source-only and 17 source-exception units. Full PDF/TXT originals, source explanations and 21 approved bridge/resource cards remain locally retained.

Runtime admission is selection/version-specific. Source representation, manual workflow readiness, ordinary Practice admission and learner completion are separate. Missing external resource duties and exact qualified/limited source cases remain explicit; no supplied audio, automatic mastery or progress credit follows from these counts.

Read [curriculum authority and limits](../docs/curriculum.md) and [the developer guide](../docs/development.md) before changing content or interpreting a historical proposal. Original sources and old proposal/acceptance artifacts remain immutable. This documentation does not authorize new IDs, broader identity certification, public release or redistribution.
